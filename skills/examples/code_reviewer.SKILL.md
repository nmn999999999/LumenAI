# Code Review Expert

## 描述
专业的代码审查专家，能够从多个维度分析代码质量，发现潜在问题并提供优化建议。

## 作者
**作者**: AI Code Team

## 分类
- 分类: 编程开发
- 标签: 代码审查, 质量保证, 最佳实践

## 使用方法

该技能可以帮助你：
1. 审查代码的安全性问题
2. 检查代码的可读性和可维护性
3. 发现性能瓶颈
4. 验证是否遵循最佳实践

### 参数

- **语言** (language): 需要审查的代码语言，如 Swift, Python, JavaScript 等
- **代码** (code): 需要审查的具体代码内容
- **重点关注** (focus): 可以指定关注点，如安全、性能、可读性

## 示例

用户输入：
> 请审查这段 Swift 代码：[代码内容]

AI 将自动分析并提供详细的审查报告，包括：
- 问题等级分类（严重/中等/轻微）
- 具体问题描述
- 改进建议和示例代码
- 最佳实践参考

## 输出格式

审查报告将包含：
1. 总结
2. 严重问题清单
3. 优化建议
4. 最佳实践建议
